## 🌟 Template Architecture & Visual Design (CycleOne.tech Style)

1. **CycleOne-Inspired Visual Experience**:
   - **Interactive Three.js Particle Canvas** (`#particleCanvas`) with dynamic mouse repulsion and subtle rotation.
   - **Sticky Navigation Bar** with gradient brand emblem, `CODE•COLLABORATE•INNOVATE` tagline, and animated underline hover effects (`.nav-line`).
   - **Hero Section** featuring animated chrome-shine gradient headline, real-time countdown timer to 28 Nov 2026, and direct CTA buttons for Day 1 PPT Submission & Devfolio.
   - **Alternating Vertical Timeline** (`#timeline`) with center glowing line, bottom dot, and hover image reveal cards for major milestones (Coding Spardha 2023, CodeRave 1.0, Reignition 2026, Day 1 Idea Forge, and Day 2 Prototype Arena).
   - **Working Model & 2-Round Structure** (`#model`) with 3D glowing border cards.
   - **Prizes Teaser Vault** (`#funding`) with sleek glassmorphism stats cards.
   - **3D Flip Card Team Grid** (`#team`) with front photo/title and back contact details with phone call and social links.
   - **Past Sponsors Showcase** (`#sponsors`) featuring Beyond Snack, Coding Minutes, INFOWIZ, 93.5 RED FM, Coca-Cola, SBI, and DELL.

2. **2-Day Tournament Architecture**:
   - **Phase 1: Idea Forge (28 Nov 2026) — PPT Submission & Screening**:
     - Both **Online (portal submission)** and **Offline (SLIET campus desk)** submission modes.
     - Evaluation of problem statements, architectures, and feasibility.
     - Announcement of shortlisted finalist teams.
   - **Phase 2: Prototype Arena (29 Nov 2026) — 24-Hour Live Demo Build Challenge**:
     - Shortlisted teams receive 24 continuous hours to build, debug, and deploy functional prototypes.
     - Mentorship and checkpoint reviews.
   - **Grand Finale — Live Pitching & Jury Verdict**:
     - Live prototype demonstrations before our distinguished jury (including Pine Labs engineers).
     - Selection and crowning of winners.

## 🛠️ Tech Stack

- **Core**: Vanilla HTML5, Vanilla JavaScript (ES Modules)
- **Styling**: Vanilla CSS (CycleOne design tokens, 3D flip card transforms, responsive media queries, Poppins typography)
- **3D Graphics & Canvas**: [Three.js](https://threejs.org/) (Interactive particle field with mouse raycasting)
- **Scroll Animations**: [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- **Visual FX**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Repository**: [https://github.com/KAMAL704/Coderave2.0.git](https://github.com/KAMAL704/Coderave2.0.git)

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/KAMAL704/Coderave2.0.git

# Navigate to project folder
cd Coderave2.0

# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build production bundle
npm run build
```
